# 机电安装专监知识 × AI智能审图工作流 v6.0 整合方案

## 一、内容对照分析

### 1.1 文档内容 vs 当前v6.0规则库

| 文档 | 核心内容 | 当前v6.0覆盖情况 | 新增价值 |
|------|---------|-----------------|---------|
| ①岗位能力与法规体系 | 监理职责、法规框架、通用验收流程 | ⚠️ 部分覆盖（有通用规则，缺监理视角） | 增加监理验收检查清单 |
| ②建筑类型与验收实战 | 住宅/商业/医疗/工业等特殊要求 | ❌ 缺失（GB 55038-2025未纳入） | 增加建筑类型专项规则 |
| ③材料阀门与系统调试 | 材料规格、阀门选型、系统调试方法 | ⚠️ 部分覆盖（有材料规则，缺调试细节） | 增加材料进场验收、系统调试检查 |
| ④甲方视角与质监验收 | 送检流程、隐蔽验收、甲方检查要点 | ❌ 缺失 | 增加甲方/质监视角的检查项 |
| ⑤具体数值与测试试验 | 各专业测试数值、试验方法、合格标准 | ⚠️ 部分覆盖（有数值，缺试验方法） | 增加试验方法指导和合格判定 |
| ⑥管线综合碰撞检测 | 碰撞分类、排布原则、净高控制、BIM应用 | ✅ 已覆盖（Step 3有碰撞检测） | 补充BIM深化设计检查 |

### 1.2 关键发现

**发现1：规则数量差异**
- 当前v6.0：262条规则（11个专业）
- 机电专监文档：提取出**200+条具体数值参数**
- 重叠度：约30%（如桥架间距、风管板厚等）
- 新增潜力：**140+条可补充规则**

**发现2：视角差异**
- 当前v6.0：**设计合规性**视角（图纸是否符合规范）
- 机电专监：**施工可实施性**视角（图纸能否顺利施工、如何通过验收）

**发现3：深度差异**
- 当前v6.0：**存在性检查**（是否提到了某参数）
- 机电专监：**合规性验证**（参数值是否正确、试验是否通过）

## 三、新增专项审查模块设计

### 3.1 模块架构

```
当前v6.0:                    新增模块:
Step 1: DXF提取              Step 1.5: 建筑类型识别
Step 2: 强条审查             Step 2.5: 材料规格审查（新增）
Step 3: 错漏排查             Step 3.5: 系统调试检查（新增）
Step 4: 跨专业校验           Step 4.5: 甲方验收检查（新增）
Step 5: 工程分析             Step 5.5: 施工可实施性分析（增强）
```

### 3.2 新增 Step 2.5: 材料规格审查模块

**功能**：检查图纸标注的材料规格是否符合国标要求

**输入**：`*_unified.json` + `project_anchor.json`（建筑类型）

**检查内容**：
1. 电缆桥架板厚 vs 宽度匹配
2. 风管板厚 vs 长边尺寸匹配
3. PPR管壁厚 vs 管径匹配
4. 配电箱钢板厚度
5. 母线槽外壳厚度 vs 电流等级匹配

**输出**：`step2_5_material_spec_result.json`

```json
{
  "summary": {
    "total_checked": 45,
    "compliant": 40,
    "non_compliant": 3,
    "need_verify": 2
  },
  "findings": [
    {
      "category": "电缆桥架板厚",
      "location": "1号楼-2层-电气平面图",
      "finding": "桥架宽度800mm，标注板厚1.2mm",
      "requirement": "宽度>800mm时板厚应≥2.0mm",
      "status": "non_compliant",
      "severity": "重要"
    }
  ]
}
```

### 3.3 新增 Step 3.5: 系统调试检查模块

**功能**：识别图纸中应包含的系统调试要求，生成调试检查清单

**输入**：`*_unified.json` + 各专业系统类型

**检查内容**：
1. 电气系统：绝缘电阻测试、接地电阻测试、漏电保护器测试
2. 给排水系统：水压试验、通球试验、满水试验
3. 暖通系统：风管漏风量测试、风量平衡调试
4. 消防系统：水泵启动时间、消火栓压力、喷头间距

**输出**：`step3_5_system_test_result.json`

```json
{
  "test_checklist": {
    "电气": [
      {"test_item": "绝缘电阻测试", "requirement": "≥0.5MΩ", "method": "500V兆欧表60秒"},
      {"test_item": "接地电阻测试", "requirement": "≤4Ω", "method": "直线法3方向平均"}
    ],
    "给排水": [
      {"test_item": "给水管道水压试验", "requirement": "1.5倍工作压力且≥0.6MPa", "method": "稳压10分钟压降≤0.02MPa"}
    ],
    "消防": [
      {"test_item": "消防水泵启动时间", "requirement": "≤55秒", "standard": "GB/T 44481-2024"}
    ]
  },
  "findings": [
    {
      "system": "消防",
      "test_item": "消防水泵启动时间",
      "finding": "设计说明未明确水泵启动时间要求",
      "suggestion": "应补充：自动启泵时间不应超过55秒（GB/T 44481-2024）",
      "status": "need_verify"
    }
  ]
}
```

### 3.4 新增 Step 4.5: 甲方验收检查模块

**功能**：从甲方/质监视角检查图纸是否满足验收要求

**输入**：`*_unified.json` + `step2_5_material_spec_result.json`

**检查内容**：
1. 材料送检要求是否明确
2. 隐蔽验收项目是否完整
3. 消防产品A签要求
4. 防火封堵检查要求
5. 分户验收项目（住宅）

**输出**：`step4_5_owner_acceptance_result.json`

## 五、实施建议

### 5.1 分阶段实施

**Phase 1（立即）：GB 55038-2025住宅新规**
- 住宅层高≥3.00m
- 卧室/起居室净高≥2.60m
- 充电桩100%配置
- 4层及以上电梯配置

**Phase 2（1-2周）：材料规格检查**
- 电缆桥架板厚
- 风管板厚
- PPR管壁厚
- 配电箱钢板厚度

**Phase 3（2-4周）：系统调试检查**
- 绝缘电阻测试
- 水压试验
- 消防水泵启动时间
- 消火栓压力

**Phase 4（4-6周）：建筑类型专项**
- 医疗建筑IT隔离电源
- 洁净手术部换气次数
- 商业建筑负荷密度

**Phase 5（6-8周）：甲方验收检查**
- 材料送检要求
- 隐蔽验收清单
- 分户验收项目

### 5.2 技术实现要点

1. **建筑类型识别**：从 project_config.json 读取建筑类型，过滤适用规则
2. **数值比较检查**：新增 `value_compare` 和 `conditional_value` 检查类型
3. **试验方法库**：建立 test_methods.json，存储各试验的标准方法
4. **检查清单生成**：新增检查清单输出格式，便于现场使用

### 5.3 与当前工作流的兼容

- 新增规则以独立文件存储（`material_spec_rules.json` 等）
- 通过配置项控制是否启用新增模块
- 原有262条规则保持不变
- 新增模块作为可选扩展
