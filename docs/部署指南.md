## 2. 安装步骤

### 2.1 安装 Python 3.11+

**Windows**:
1. 访问 https://www.python.org/downloads/ 下载 Python 3.11+
2. 安装时勾选 "Add Python to PATH"
3. 验证安装：
   ```bash
   python --version
   ```

**Linux (Ubuntu/Debian)**:
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
python3 --version
```

### 2.2 安装依赖包

```bash
# 安装核心依赖
pip install ezdxf openai requests

# 验证安装
python -c "import ezdxf; print(ezdxf.__version__)"
python -c "import openai; print(openai.__version__)"
```

### 2.3 获取项目代码

将项目目录 `f:\AI智能审图系统_v6.0_项目开发` 复制到目标部署位置，或通过版本控制工具获取。

## 4. 配置说明

### 4.1 项目配置

编辑 `config/project_config.json` 调整以下配置：

```json
{
  "paths": {
    "input_dir": "./input",
    "output_dir": "./output",
    "config_dir": "./config",
    "log_dir": "./output/logs"
  },
  "performance": {
    "max_file_parse_time": 5,
    "max_rule_check_time": 30,
    "max_report_gen_time": 10,
    "max_memory_usage": 500,
    "lru_cache_size": 128,
    "enable_performance_monitor": true
  },
  "logging": {
    "level": "INFO",
    "file": "./output/logs/system.log"
  },
  "building_type": {
    "default": "住宅",
    "supported": ["住宅", "公建"]
  }
}
```

### 4.2 强制性规则配置

无需修改 `config/rules.json`，系统已内置 280 条强制性规则，覆盖6大专业+公建专用规则，采用四级风险分级（高/中/低/提示）。如需定制规则，参照以下格式添加：

```json
{
  "rule_id": "rule_281",
  "category": "建筑",
  "description": "规则描述",
  "keywords": ["关键词1", "关键词2"],
  "regex": "正则表达式",
  "severity": "高",
  "risk_level": "高",
  "standard_code": "GB XXXX-XXXX 第X.X.X条",
  "building_type": ["住宅", "公建"]
}
```

### 4.3 LLM配置

系统默认集成智谱GLM-4-Flash大语言模型，用于智能审查辅助。编辑 `config/project_config.json` 中的 `llm` 配置段：

```json
{
  "llm": {
    "provider": "zhipu",
    "model": "glm-4-flash",
    "api_key": "",
    "base_url": "https://open.bigmodel.cn/api/paas/v4",
    "enabled": true,
    "timeout": 30,
    "max_retries": 3,
    "temperature": 0.1
  }
}
```

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `provider` | LLM服务商 | `zhipu` |
| `model` | 模型名称 | `glm-4-flash` |
| `api_key` | API密钥（建议通过环境变量设置） | 空 |
| `base_url` | API基础URL | `https://open.bigmodel.cn/api/paas/v4` |
| `enabled` | 是否启用LLM | `true` |
| `timeout` | 请求超时（秒） | `30` |
| `max_retries` | 最大重试次数 | `3` |
| `temperature` | 生成温度 | `0.1` |

## 5. 运行指南

### 5.1 基本运行

```bash
# 进入项目目录
cd f:\AI智能审图系统_v6.0_项目开发

# 执行全流程9步审查
python src/master.py
```

### 5.2 指定输入输出目录

```bash
python src/master.py --dxf-dir ./input --json-dir ./json_data --output-dir ./output
```

### 5.3 部分执行

```bash
# 跳过DXF提取（已有JSON时）
python src/master.py --skip-step 1

# 仅执行第2、3步
python src/master.py --only-step 2 3

# 执行到第3步后停止
python src/master.py --stop-after 3

# 预览执行计划（不实际运行）
python src/master.py --dry-run
```

### 5.4 单步执行

```bash
# 仅执行初始化
python src/step0_init.py --output-dir ./output

# 仅执行DXF提取
python src/step1_extract.py --dxf-dir ./input --output-dir ./json_data

# 仅执行合规审查
python src/step2_compliance.py --json-dir ./json_data --output-dir ./output

# 仅执行错漏排查
python src/step3_defect.py --json-dir ./json_data --output-dir ./output

# 仅执行跨专业校验
python src/step4_cross_check.py --json-dir ./json_data --output-dir ./output

# 仅执行工程分析
python src/step5_engineering.py --json-dir ./json_data --output-dir ./output

# 仅执行问题持久化
python src/step6_persistence.py --json-dir ./json_data --output-dir ./output

# 仅执行报告生成
python src/step7_report.py --json-dir ./json_data --output-dir ./output

# 仅执行汇总输出
python src/step8_summary.py --json-dir ./json_data --output-dir ./output
```

## 8. 常见问题

### 8.1 ezdxf 安装失败

```bash
# Windows: 使用预编译wheel
pip install --only-binary=ezdxf ezdxf

# Linux: 安装系统依赖
sudo apt install libcairo2-dev
pip install ezdxf
```

### 8.2 编码错误

在 Windows 上运行 DXF 提取时，如遇编码错误，设置环境变量：
```bash
set PYTHONUTF8=1
python src/step1_extract.py
```

### 8.3 路径问题

确保输入路径使用绝对路径或相对于项目根目录的正确相对路径：
```bash
python src/master.py --dxf-dir "F:\AI智能审图系统_v6.0_项目开发\input"
```

### 8.4 LLM API连接失败

如LLM服务不可用，可通过以下方式排查：
1. 检查 `LLM_API_KEY` 环境变量是否已设置
2. 检查网络连接是否正常
3. 在 `project_config.json` 中设置 `"llm": {"enabled": false}` 临时禁用LLM，系统将以纯规则模式运行

## 9. 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PIPELINE_DXF_DIR` | `/workspace/.uploads` | DXF 文件目录 |
| `PIPELINE_JSON_DIR` | `./json_data` | JSON 文件目录 |
| `PIPELINE_OUTPUT_DIR` | `./output` | 输出目录 |
| `PYTHONUTF8` | 未设置 | Windows UTF-8 模式 |
| `LLM_API_KEY` | 未设置 | LLM API密钥（智谱GLM） |
| `LLM_BASE_URL` | `https://open.bigmodel.cn/api/paas/v4` | LLM API基础URL |
| `LLM_MODEL` | `glm-4-flash` | LLM模型名称 |
| `LLM_ENABLED` | `true` | 是否启用LLM |
