# 施工图智能审查系统 v6.0 - 技术架构文档

## 1. 系统概述

施工图智能审查系统 v6.0 是一个基于 Python 的命令行工具，采用 **9步分步工作流** 架构，对 DXF 格式施工图纸进行自动化智能审查。系统覆盖 **建筑、结构、暖通、给排水、电气、消防** 6大专业的 **280条** 审查规则（含23条公建专用规则），支持锚点提取、标高计算、碰撞检测、管线综合、跨专业校验、工程落地分析、BIM管线、RAG审核、二次审查等核心功能，并集成智谱 glm-4-flash 大语言模型实现智能判定与审核。

## 3. 分步工作流详解

### Step 0: 锚点提取

- **脚本**: `src/step0_anchor.py`
- **输入**: DXF 文件目录
- **输出**: 锚点数据文件
- **核心功能**:
  - 从DXF图纸中提取关键锚点信息
  - 建立图号、楼层、轴线范围的基准定位
  - 为后续步骤提供位置信息基础

### Step 1: DXF图纸参数提取

- **脚本**: `src/step1_extract.py`
- **输入**: DXF 文件目录
- **输出**: `*_unified.json` 汇总文件
- **核心功能**:
  - 扫描指定目录下的所有 `.dxf` 文件
  - 提取 TEXT/MTEXT 实体文本
  - 根据两级策略（文件名→内容语义）推断专业类别（建筑/结构/暖通/给排水/电气/消防），未识别率2.7%
  - 提取标高数据（正则匹配 `±?\\d+\\.\\d{2,3}\\s*m?`）
  - LLM辅助标高提取（智谱glm-4-flash）
  - 文本清理：去重、去空白、去纯数字
  - 输出按楼栋-专业分类的统计信息

### Step 2: 强制条文合规性审查

- **脚本**: `src/step2_compliance.py`
- **输入**: `*_unified.json` 文件目录
- **输出**: `step2_compliance_result.json`
- **核心功能**:
  - 加载 JSON 文件到 JsonLoader
  - 加载 280条审查规则（config/rules.json），含23条公建专用规则
  - 建筑类型适配：公建/住宅规则自动过滤
  - 逐条规则关键词 + 正则匹配审查
  - LLM辅助合规判定（智谱glm-4-flash）
  - 经验匹配引擎联动（ExperienceMatcher）
  - 规范数据库加载（config/normative_database.json）
  - 文件名清洗（UUID 转可读名称）
  - 证据链三级校验（L0-L3）
  - 四级风险分级：严重(强条违反) / 重要(非强条违规) / 一般(待核实) / 提示(合规)

### Step 3: 基础错漏排查

- **脚本**: `src/step3_defect.py`
- **输入**: `*_unified.json` 文件目录
- **输出**: `step3_defect_result.json`
- **核心功能**:
  - 标高计算与净高验算（ElevationCalc）
  - 8类碰撞检测（CollisionDetect）：桥架碰撞、次梁阻挡、管线间距、吊顶空间、柱管碰撞、风管喷淋间距、电气消防燃气距离、桥架细节
  - 轴线定位算法碰撞检测（AxisCollisionDetector）
  - 几何碰撞检测（GeometricCollision）：跨专业标高+轴线碰撞
  - 管线综合排布分析（MepCoordinator）
  - 几何空间分析（可选，需 DXF 文件）：构件重叠检测、间距不足检测、标注异常检测等（GeometryExtractor + GeometryAnalyzer）

### Step 4: 跨专业一致性校验

- **脚本**: `src/step4_cross_check.py`
- **输入**: `*_unified.json` 文件目录
- **输出**: `step4_cross_check_result.json`
- **核心功能**:
  - 基础比对：标高一致性、轴线一致性、构件位置参考
  - 深度比对（6项）：梁高 vs 净高、管线 vs 设备位置、消防管道 vs 防火分区、桥架 vs 其他管线、风管 vs 结构预留洞、给排水 vs 结构

### Step 5: 工程落地分析 + 报告生成

- **脚本**: `src/step5_engineering.py`
- **输入**: `*_unified.json` 文件目录 + step2/step3/step4 中间结果
- **输出**: 6份报告 + `issues_snapshot.json`
- **核心功能**:
  - EngineeringAnalyzer 全周期分析：复杂度评估、风险等级评估、工程量鉴定、工期可行性、成本估算、风险识别、优化建议、全生命周期评分
  - LLM辅助工程分析（智谱glm-4-flash）
  - 施工排程分析（construction_schedule.py v2.0）
  - 生成 6 份报告：
    1. 强条合规性审查报告
    2. 基础错漏排查报告
    3. 跨专业一致性校验报告
    4. 综合评估摘要报告
    5. 图纸会审问题清单
    6. LLM分析报告
  - 问题清单持久化（跨次对比）

### Step 6: BIM管线

- **脚本**: `src/step6_bim.py`
- **输入**: `*_unified.json` 文件目录 + 前序步骤中间结果
- **输出**: BIM管线分析结果
- **核心功能**:
  - BIM管线综合分析
  - 管线碰撞检测与优化建议
  - 与Step3管综分析联动

### Step 7: RAG审核

- **脚本**: `src/step7_rag.py`
- **输入**: 前序步骤中间结果
- **输出**: RAG审核结果
- **核心功能**:
  - 基于检索增强生成的审核
  - LLM辅助RAG审核（智谱glm-4-flash）
  - 规范条文智能匹配与校验

### Step 8: 二次审查

- **脚本**: `src/step8_review.py`
- **输入**: 前序步骤中间结果
- **输出**: 二次审查结果
- **核心功能**:
  - 对前序步骤审查结果进行二次校验
  - LLM辅助二次审查（智谱glm-4-flash）
  - 误报过滤与漏报补充
  - 最终审查结论确认

## 8. 四级风险分级

系统对审查结果实行四级风险分级：

| 等级 | 标识 | 说明 |
|------|------|------|
| 严重 | 强条违反 | 违反强制性条文，必须整改 |
| 重要 | 非强条违规 | 违反非强制性条文，建议整改 |
| 一般 | 待核实 | 需进一步核实确认 |
| 提示 | 合规 | 符合规范要求 |

## 9. 证据链校验机制

系统实现 L0-L3 四级证据链校验：

| 等级 | 条件 | 说明 |
|------|------|------|
| L0-无证据 | 缺少 file 或 evidence | 最低置信度 |
| L1-基础 | 有 file + evidence，但缺少 line 或 rule_id | 基础证据链 |
| L2-增强 | 有 file + evidence + line + rule_id | 增强证据链 |
| L3-完整 | 有 file + evidence + line + rule_id + code_reference | 完整证据链 |

## 11. 性能优化

### 11.1 LRU缓存

- **模块**: `engine/lru_cache.py`
- **功能**: 对频繁访问的规则配置、规范数据、中间结果进行缓存
- **策略**: 最近最少使用淘汰，自动管理缓存容量

### 11.2 性能监控

- **模块**: `engine/performance_monitor.py`
- **功能**: 运行时性能指标采集与报告
- **指标**: 步骤执行耗时、内存占用、缓存命中率
