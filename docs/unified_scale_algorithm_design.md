# 统一比例尺识别算法设计文档

## 1. 问题背景

在当前 AI 智能审图系统中，不同专业、不同图纸的比例尺不统一，导致:
- 坐标值不一致，跨专业碰撞检测错误
- 尺寸标注与实际图形不匹配
- 标高计算错误
- 综合评估报告错误（如之前发现的问题）

## 2. 算法设计目标

### 2.1 核心目标
- 自动识别不同图纸的比例尺
- 将所有图纸坐标统一转换为毫米单位
- 提供比例尺一致性验证
- 支持多图纸批量处理

### 2.2 设计原则
- 高可靠性：多源数据交叉验证，降低误识别风险
- 可扩展：支持新增识别策略
- 可追溯：记录比例尺识别过程，支持人工审核
- 高性能：支持大文件快速处理

## 3. 算法架构

### 3.1 识别策略优先级（按置信度排序）

| 优先级 | 策略 | 说明 | 置信度基准 |
|--------|------|------|-----------|
| 1 | DXF $INSUNITS 系统变量 | DXF 标准单位定义 | 0.95 |
| 2 | 图纸文本中的比例标注 | 如"1:100"、"比例 1:50" | 0.85 |
| 3 | 标准图框尺寸匹配 | A0/A1/A2/A3/A4 标准尺寸 | 0.80 |
| 4 | 已知构件尺寸验证 | 管道、墙体、柱子等标准尺寸反向验证 | 0.75 |
| 5 | 坐标范围推断 | 基于建筑工程常见坐标范围 | 0.60 |

### 3.2 算法流程

```
开始
  ↓
读取 DXF 文件
  ↓
并行执行所有识别策略
  ↓
收集各策略结果及置信度
  ↓
多源数据融合与冲突解决
  ↓
构件尺寸反向验证
  ↓
输出最终比例尺与置信度
  ↓
坐标统一转换为毫米
  ↓
多图纸一致性验证
  ↓
结束
```

## 4. 核心算法模块

### 4.1 多策略并行识别器

```python
class UnifiedScaleRecognizer:
    def __init__(self):
        self.strategies = [
            InsUnitsStrategy(),      # $INSUNITS 策略
            TextScaleStrategy(),     # 文本比例策略
            FrameSizeStrategy(),     # 图框尺寸策略
            KnownElementStrategy(),  # 已知构件策略
            CoordinateRangeStrategy() # 坐标范围策略
        ]
```

### 4.2 置信度加权融合

使用加权投票法融合多策略结果：

- 权重 = 策略基准置信度 × 结果一致性系数
- 最终比例尺 = Σ(权重_i × 比例尺_i) / Σ(权重_i)

### 4.3 构件尺寸反向验证

使用已知标准构件尺寸验证比例尺正确性：
- 管道直径：50mm, 75mm, 100mm, 150mm, 200mm...
- 墙体厚度：100mm, 120mm, 150mm, 200mm, 240mm...
- 柱子尺寸：300mm, 400mm, 500mm, 600mm...
- 风管宽度：200mm, 320mm, 400mm, 500mm...

验证方法：计算识别后的尺寸与标准尺寸的匹配度

## 5. 输出数据结构

```python
@dataclass
class UnifiedScaleResult:
    scale_factor: float           # 坐标 × scale_factor = mm
    unit_code: int                # DXF $INSUNITS 代码
    unit_name: str                # 单位名称
    confidence: float             # 总体置信度 0-1
    method: str                   # 主要识别方法
    method_details: Dict[str, float]  # 各策略详细结果
    validated: bool               # 是否通过构件验证
    validation_score: float       # 验证得分
    source_file: str              # 源文件
    warnings: List[str]           # 警告信息
```

## 6. 集成方案

### 6.1 集成到 DXF 解析流程

在 `OptimizedDxfParser` 中集成比例尺识别：
1. 解析前先识别比例尺
2. 解析过程中应用比例尺转换
3. 输出统一毫米单位的几何数据

### 6.2 多图纸一致性验证

新增 `MultiFileScaleValidator` 类：
1. 批量识别所有图纸比例尺
2. 检测异常值
3. 提供统一校正建议

## 7. 性能优化

- 策略并行执行
- 构件采样验证（避免全量验证）
- 结果缓存（相同图纸重复使用）

## 8. 错误处理

- 单策略失败不影响整体流程
- 提供降级方案
- 详细日志记录
