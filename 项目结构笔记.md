# AI-CAD-Audit-System v7.0 项目结构笔记

## 一、根目录概览
```
f:\AI-CAD-Audit-System\
├── .venv/                    # Python虚拟环境
├── src/                      # 源代码主目录
│   ├── output_v7.0/          # 输出报告目录
```

```
│   └── engine.py             # 检查引擎
```

## 三、关键依赖
- Flask: Web框架
- ezdxf: DXF图纸处理
- openai: LLM调用
- lxml: XML处理
- docx: Word报告生成

## 四、调试关注点
1. **启动流程**: Start.bat → launcher.py → admin/server.py
2. **数据库**: SQLite (v7_data.db)
3. **图纸输入**: v7/input/ 目录
4. **报告输出**: src/output_v7.0/ 目录
